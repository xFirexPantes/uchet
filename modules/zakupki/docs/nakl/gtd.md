# Загрузка ГТД

Открывается кнопкой **ГТД** в накладной. Окно есть только у поставщиков, для которых в карточке фирмы указан разборщик файла.
Перед открытием в накладной должны быть заполнены номер и продавец.

Сейчас работают: Компэл, Акрол (Форвард), Витал, Алеф, Элсио, Алкон. Остальным поставщикам (Симметрон, Стрела, SkyParts, Торекс, Радио)
нужна общая папка `\\TSRV\Basa\Prices` на сервере, поэтому для них загрузка пока не перенесена: кнопка выдаёт сообщение.

## Как пользоваться
1. **📂 Загрузить файл**: выберите Excel-файл поставщика (.xls или .xlsx). Из файла берутся только строки с номером нашей накладной.
   Строки появляются внизу, в списке «Позиции в файле». Зелёная «Маркировка» означает, что строка уже сопоставлена с позицией счёта.
2. Щелчок по строке файла выделяет её позицию счёта вверху, если строка сопоставлена.
3. **Сопоставить**: выделите позицию счёта вверху и строку файла внизу. Если строка уже сопоставлена, будет вопрос:
   «Да» заводит ещё одну строку, «Нет» заменяет сопоставление.
4. **−**: удалить сопоставление выделенной строки файла.
5. **⇩ Выгрузить в накладную**: строки файла (ГТД, страна) переносятся в накладную, окно закрывается.
   Если есть несопоставленные строки, их «В накл» станет красным. Если количество в файле больше, чем в счёте, будет вопрос.
6. **✕**: закрыть окно. Строки накладной перечитываются.

## Отличия от Access
- Файл выбирается в браузере и читается на сервере. Excel на компьютере не нужен.
- Пометка «загружено» в самом файле не ставится.
- Вопроса «Использовать файл …?» нет: файл выбирают каждый раз.
