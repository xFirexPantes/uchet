# Добавить позиции в накладную

Открывается кнопкой ＋ в накладной. В списке позиции счёта, которые ещё не попали в накладные.

## Как пользоваться
- В столбце **Кол-во** укажите, сколько штук каждой позиции добавить. Пустое или 0 означает «не добавлять».
- Количество не может быть больше, чем осталось по счёту. Иначе будет сообщение «Количество по накладной больше, чем в счёте».
- **✓**: добавить отмеченные позиции. Накладная перейдёт в режим правки.
- **✕**: закрыть окно, ничего не добавляя.
