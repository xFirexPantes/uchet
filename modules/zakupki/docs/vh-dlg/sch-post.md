# Переписка по счету

Письма по счёту. Открывается кнопкой «Переписка» во «Входящих счетах» (если у счёта есть TP) и ✉ в карточке счёта.

- **＋** — добавить письмо: окно [«Создание переписки»](mail-add.md), после добавления список перечитывается.
Правка прямо в списке, как в Access:
- двойной щелчок по **Примечанию** или **Ответу** — окно с текстом (примечание до 255 символов, ответ до 1024);
- двойной щелчок по **Кому** — новый адрес (проверяется, что это e-mail); по **Кто ответил** — имя; по **Когда ответил** — календарь;
- щелчок по флажку **Получен ответ** — включить / выключить;
- **Delete** — очистить поле, по которому последний раз щёлкнули (примечание, кому, ответ, кто ответил, дата ответа);
- двойной щелчок по **Файл** — скачать прикреплённый файл, а если файла нет — выбрать и прикрепить (копия в папку фирмы «…\\Переписка» на \\TSRV);
- **Delete** на «Файле» — удалить файл (после вопроса «Удаляем?»).

- **−** — удалить выбранное письмо (после вопроса «Удаляем?»). Без права — «У Вас нет прав на данное действие».
- **✕** — закрыть; строка счёта в списке перечитывается (число писем).

## Отличия от Access
- Работа с файлами требует, чтобы папка \\TSRV была подключена на сервере с правом записи.
