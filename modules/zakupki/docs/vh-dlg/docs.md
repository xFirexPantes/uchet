# Письма

Кнопка «Письма» во «Входящих счетах»: письма по выбранному счёту (номер и дата).

- **✕** или Esc — закрыть.

## Отличия от Access
- Двойной щелчок по письму пока ничего не делает (подформа subfrmFndDocs ещё не перенесена).
