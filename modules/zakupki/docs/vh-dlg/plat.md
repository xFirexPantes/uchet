# Платежи по счёту

Платёжки из 1С по выбранному счёту (кнопка «Платежи» во «Входящих счетах»).

- **✉ отправить e-mail** — письмо поставщику об оплате выбранной платёжки: открывается окно [«Письмо»](mail-txt.md).
  Можно из состояния «не отправлено»; если письмо уже отправляли, а платёжку перепровели — после вопроса. Иначе «Из указанного состояния нельзя отправить письмо».
- **⊘ не надо отправлять** — пометить платёжку «не отправлять» (из состояний 0, 2, 3).
- **✕** — закрыть; строка счёта перечитывается (цвет «Оплата»).

Для счетов на детали кнопок отправки нет.

## Отличия от Access
- Нет отличий в столбцах: «№ и дата плат.», «Дата оплаты», «Сумма», «Инфо» — как в подформе SubFrmPlatFrom1C.
