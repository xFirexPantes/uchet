# Письмо по счёту

Открывается кнопкой ✉ во «Входящих счетах» (письмо поставщику) или «отправить e-mail» в окне «Платежи по счёту» (письмо об оплате).

- Список вверху — шаблоны текста. Выбранный шаблон попадает в поле «Текст», его можно поправить.
- **＋** — добавить текст в справочник (если такой уже есть, он будет выбран). **✎** — сохранить правку выбранного шаблона.
- **E-mail** — кому (адрес поставщика подставляется сам). **От** — от чьего имени письмо.
- **✉ Сформировать письмо** — отправить. В тексте заменяются: [Sch] — номер счёта, [Dta] — дата счёта, [Org] — TP;
  в письме об оплате ещё [Sm] — сумма, [PP] — номер платёжки, [DtaPP] — её дата, тема «Оплата по счёту N от дата».
  После отправки строка счёта (или платёжки) отмечается, окно закрывается.

## Отличия от Access
- Письмо уходит с почтового адреса сервера, адрес «От» ставится в «Ответить». С тестовой базы — только на тестовый адрес, без настроек почты — в файлы.
- Адрес «От» по умолчанию в Access брался из учётной записи Outlook Express (GetDefaultMail). Здесь браузер запоминает «От» после удачной отправки и подставляет его в следующий раз; после ввода или подстановки список шаблонов перечитывается.
- Вопроса «отправить через другой SMTP-сервер» нет: при ошибке показывается её текст.
