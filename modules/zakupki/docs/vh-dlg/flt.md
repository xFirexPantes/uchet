# Фильтр по счетам

Открывается кнопкой **▼** во «Входящих счетах».

- **Фирма** — продавец из списка фирм, по которым есть счета за указанные даты. Пустое значение — все продавцы.
- Двойной щелчок по фирме — окно «Выбор фирмы и холдинга» (от 4 букв, по датам фильтра); выбранный холдинг становится фирмой фильтра.
- **с / по** и **Интервал** — даты. После смены дат список фирм перечитывается, выбранная фирма остаётся.
- **✓** — применить: фирма и даты переносятся на экран, поиск выполняется сразу.
- **⌫** — снять фильтр: фирма и даты очищаются (без дат ищется с 01.01.2000 по сегодня).
- **✕** или Esc — закрыть без изменений.

## Отличия от Access
- Создание новой фирмы с холдингом (frmfndHolding, режим 0) не перенесено.
- Итоговая сумма над списком, как в Access, фирму не учитывает.
