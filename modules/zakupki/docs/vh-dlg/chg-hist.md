# История изменений счетов

Два режима:
- **Из «Входящих счетов»** (кнопка «Ист») — изменения по всем счетам, которые сейчас в списке. В шапке фильтры:
  «Изменение с … по …» (по умолчанию последний месяц, кнопка «Даты»), «Событие», «Причина», «№ счёта», «Дата счёта» (кнопка «Даты»), «Продавец».
  Событие, причина и продавец выбираются двойным щелчком, клавиша Delete очищает фильтр. № счёта применяется по Enter или при уходе из поля.
- **Из карточки счёта** (кнопка «Ист» у позиций) — изменения выбранной позиции. Галка «Все изменения по счёту» показывает изменения всего счёта.
  Столбцы «№ счёта», «Дата счёта», «Продавец» здесь скрыты.

Внизу: число строк и суммы изменений в рублях и долларах.

**✎ Изменить причину** (нужно право ChgPredShcetaHst): выбрать причину, ввести комментарий — у выбранной строки причина меняется.

## Отличия от Access
- Фильтр «Дата счёта» в Access не работал (ошибка в сборке параметров), здесь работает.
- «К» (карточка элемента) пока неактивна.
- Справочник причин (добавить / изменить / удалить в окне выбора) пока не перенесён.
- В режиме карточки итоги стоят в видимой части окна (в Access они были за правым краем).
