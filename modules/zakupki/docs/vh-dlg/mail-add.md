# Создание переписки

Открывается кнопкой **＋** в окне [«Переписка по счету»](sch-post.md). Добавляет запись о письме по счёту.

- **Тип письма** — обязателен. Для типа 5 появляются **Ответ**, **Кто ответил** и **Файл**.
- **Файл** — двойной щелчок выбирает файл; при «Добавить» он копируется в папку фирмы «…\\Переписка» на \\TSRV.
- **Примечание** — до 255 символов.
- **email** — адрес получателя, подставляется по счёту; обязателен.
- **Добавить** — проверить и сохранить; окно закрывается, список писем перечитывается.
- **✕** — закрыть без сохранения.

## Отличия от Access
- В Access в письмо записывался путь к файлу на компьютере пользователя, здесь — путь к копии на \\TSRV (как в переписке).
