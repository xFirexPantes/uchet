# Изменение даты поставки счёта

Кнопка «Ист» (история дат поставки) в карточке счёта: история изменения даты поставки выбранной позиции.

- Список внизу — вариант истории; после выбора список и заголовок окна перечитываются.
- Столбцы раздвигаются мышью, ширины запоминаются.
- **✕** или Esc — закрыть.
