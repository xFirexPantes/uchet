# Сроки КОМПЭЛ

Кнопка «Сроки КОМПЭЛ» во «Входящих счетах». Сразу открывается выбор файла Excel (.xls или .xlsx) — файл поставщика
проверяется и загружается так же, как в [«Сроки поставки»](srok.md) для КОМПЭЛ.

После загрузки для каждой строки файла, у которой резерв ещё не выбран, открывается окно **«Выбор резерва счёта»**
(frmfndPR, режим 155): список резервов по строке, три столбца. Двойной щелчок или ✓ — выбрать, Esc или ✕ — отказаться.

- Выбранный резерв сразу сохраняется, и открывается окно для следующей строки.
- Отмена выбора или ✕ в окне резерва **прерывает цикл**: остальные строки остаются без резерва (как в Access).
- Когда строки кончились — сообщение «Загрузка завершена».

## Отличия от Access
- Файл сначала проверяется, потом копируется на \\TSRV.
- Резервы сохраняются по одному, сразу после выбора (в Access так же, но цикл шёл без обновления экрана).
- Строки с уже выбранным резервом в цикл не попадают: берутся только `Idres = -1` текущего пользователя.
