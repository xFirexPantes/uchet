# Забрать товар

Кнопка «Тов» во «Входящих счетах». Список товара, который нужно забрать.

- **Фильтр**: «Забрать» или «Доставлено».
- Флажки **Писать адрес** и **Доставлено** в списке меняются щелчком; не получилось — «Не удалось изменить состояние флажка».
- **XLS** — выгрузка в Excel (книжная страница, по ширине одна страница): скачивается файл, окно закрывается.

## Отличия от Access
- В Access книга открывалась в Excel сразу, здесь файл скачивается.
