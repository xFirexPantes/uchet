# Акты и отчёты

Кнопки «Акт» и «Отчет» во «Входящих счетах» (видны, если у счёта есть акты / отчёты). Список по TP счёта.

- **Открыть** — файл выбранного акта (путь из xp_GetData4AktDefGetFileF6_3) или отчёта о входном контроле
  (папка адреса 19, «Ф5-1-2004 / Ф5-3-2015 / Ф5 Отчет о входном контроле<№>.xls» по номеру). Нет файла — «Не найден файл».

## Отличия от Access
- Файл скачивается браузером, а не открывается в Excel. Сервер читает \\TSRV через подключённую папку (настройка `uncMap` в config/local.php); пока она не настроена — «Не найден файл».
