# Склад (полный поиск компонента)

Открывается из карточки счёта на элементы (＋, ответ «Нет» на вопрос об облегчённой версии) и из позиции счёта на детали
(двойной щелчок по «Номенклатуре»).

## Как найти элемент
- **Дерево слева**: Склад → счёт учёта (например, 10.1) → элемент → серия → наименование → номинал → корпус → изготовитель.
  Щелчок по узлу раскрывает его и показывает элементы справа.
- **Поиск**: наберите 3 символа и больше, список обновится через секунду. Строку со «*» ищите по Enter.
  Если найден один элемент, он выбирается сразу.
- **Поиск по маркировке**: ищет по маркировке, вместе со строкой поиска или без неё (по Enter или при уходе из поля).
- **Максимум строк**: сколько строк показывать по узлу дерева. **Вывести все** показывает все. После поиска «Вывести все» включается само.
- Переключатели «НЕ давальческое сырьё / Давальческое сырьё / …», «Показываемые / Удалённые», «Пантес / Торэкс / Не важно», флажки
  ВП5, «Без аналогов», «Неликвид», ПГ, E-find и «Принадлежность» перестраивают дерево и список.
- Щелчок по заголовку столбца сортирует список, повторный щелчок сортирует в обратную сторону. Ширину столбцов можно менять мышью.

## Выбор
Щелчок по строке выбирает элемент (его код в поле ID) и раскрывает дерево до него. **✓** или двойной щелчок передаёт элемент в окно,
из которого открыли поиск. **✕** закрывает без выбора. ⧉ копирует наименование, 📋 — полное наименование.

## Пока не работает
Фото элемента, «Склады поставщиков», составляющие детали (кнопка «Сост» у счёта на детали). Заголовки столбцов списка названы по полям,
настоящие подписи из Access уточняются.

## Отличия от Access
В Access после выбора в карточке счёта окно «Склад» оставалось открытым за окном позиции. Здесь оно закрывается.
Вопрос «Открыть облегчённую версию?» при открытии окна не задаётся (флажок «Облегчённая версия» в Access скрыт).
