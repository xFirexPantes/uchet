# Список элементов, требующих внимания

Появляется при первой оплате счёта («+» у «Процентов/сумм оплат»), если по элементам счёта есть что проверить.
Только просмотр. **✓** — продолжить оплату, **✕** (или Esc) — отказаться. Столбцы раздвигаются мышью.
