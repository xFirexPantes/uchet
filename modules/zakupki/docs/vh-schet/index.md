# Входящие счета

Для кого: снабжение.
Что делает: список входящих счетов за период с фильтрами, итоговая сумма, сведения по выбранному счёту (суммы, оплаты, «к оплате», платежи из 1С). Двойной щелчок открывает карточку счёта.

## Фильтры
- **Счета с … по …**: период. По умолчанию последний год.
- **№ счёта**: поиск по части номера.
- **Сырьё**: НЕ давальческое / давальческое / не важно.
- **Все счета**: без галочки показываются только открытые.
- **Счета на**: элементы или детали.

## Цвета в списке
Цвета приходят из процедуры `xp_GetAllSch`, как в Access. Расшифровка: забрать полностью / частично, задерживаются, проблемные, не отправлено, прошла ДП, разница дат больше 2 недель, письмо отправлено, отдано в оплату, закрыто к оплате, нет пути.

## Отличия от Access
- Список сортируется щелчком по заголовку, как раньше. Повторный щелчок меняет направление.
- Панель справа пока только для просмотра. Изменение оплат, «Кто забирает», примечаний и кнопки внизу формы будут добавлены позже.
