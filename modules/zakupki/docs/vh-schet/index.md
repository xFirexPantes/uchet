# Входящие счета

Для кого: снабжение.
Что делает: список входящих счетов за период с фильтрами, итоговая сумма, сведения по выбранному счёту (суммы, оплаты, «к оплате», платежи из 1С). Двойной щелчок открывает карточку счёта.

## Фильтры
- **Счета с … по …**: период. По умолчанию последний год.
- **№ счёта**: поиск по части номера.
- **Сырьё**: НЕ давальческое / давальческое / не важно.
- **Все счета**: без галочки показываются только открытые.
- **Счета на**: элементы или детали.
- **Интервал**: окно «интервал дат» — месяц, квартал, год или день, «+»/«−» листают период; ✓ подставляет даты и сразу ищет.
- **▼ Фильтр** — окно [«фильтр по счетам»](../vh-dlg/flt.md): продавец и даты. Галка «фильтр» слева вверху стоит, когда задан хоть один фильтр.

## Цвета в списке
Цвета приходят из процедуры `xp_GetAllSch`, как в Access. Расшифровка: забрать полностью / частично, задерживаются, проблемные, не отправлено, прошла ДП, разница дат больше 2 недель, письмо отправлено, отдано в оплату, закрыто к оплате, нет пути.

## Отличия от Access
- Список сортируется щелчком по заголовку, как раньше. Повторный щелчок меняет направление.
- «Кто забирает» (Осташов / Наумов) сохраняется сразу при выборе. Если сохранить не удалось, вернётся прежнее значение.
- Путь к счёту внизу: двойной щелчок скачивает файл счёта, а если пути нет — предлагает выбрать файл: он копируется в папку фирмы на \\TSRV (если такой файл уже есть, к имени добавляются дата и время), путь сохраняется. Delete удаляет путь (после вопроса).
- ✎ у «Примечания» и двойной щелчок по «Комментарию» открывают окно ввода текста (справка в нём, F1).
- Оплаты: «−» у «Процентов/сумм оплат» удаляет выбранную строку (без вопроса, как в Access); «✓» меняет состояние счёта «закрыт к оплате» (после вопроса);
  «−» у «К оплате» удаляет выбранную строку (после вопроса). После этого списки панели и строка счёта перечитываются.
- «+» у «Процентов/сумм оплат» отдаёт счёт в оплату. Сначала может появиться сообщение о договоре поставки (сумма выше порога, а договора нет или срок гарантии меньше 12 месяцев) — оно только предупреждает.
  Если оплат ещё нет и есть элементы, требующие внимания, открывается их список: ✓ — продолжить, ✕ — отказаться.
  Дальше возможны вопросы: команды к оплате уже покрывают счёт; счёт оплачен больше, чем указано командами (можно ввести корректирующую запись); сумма счёта выше порога.
  Затем окно [«Оплатить»](get-prc.md): число и «процентов» (целое, до 100) или «рублей» (сумма; можно отключить проверку). После записи спрашивается «Отправить письмо об оплате?»;
  письмо о большой сумме уходит в любом случае, если процедура его готовит. С тестовой базы письма идут только на тестовый адрес, без настроек почты — в файлы.
- «+» у «К оплате» заводит строку: после вопроса о сумме выше порога открывается окно [«К оплате»](get-prc.md) с датой оплаты, «не позднее», комментарием и суммой.
- «Долги» (внизу формы): выберите покупателя в окне «Выбор покупателя» (двойной щелчок или ✓) — скачается файл Excel с долгами по нему:
  заголовки на сером фоне, под данными сумма столбца F. Если данных нет — сообщение «Нет данных для выгрузки». В Access книга открывалась в Excel сразу, здесь файл скачивается.
- Кнопки окон второй очереди:
  «Ист» — [история изменений](../vh-dlg/chg-hist.md) по всем счетам списка; ✉ — [письмо поставщику](../vh-dlg/mail-txt.md)
  (если письмо по счёту уже отправляли, сначала вопрос «Отправить ещё раз?»); «Переписка» — [письма по счёту](../vh-dlg/sch-post.md) (если у счёта есть TP);
  «Платежи» — [платежи из 1С](../vh-dlg/plat.md); «Тов» — [«Забрать товар»](../vh-dlg/get-tov.md); «Акт» / «Отчет» — [список актов и отчётов](../vh-dlg/acts.md).
- **Сроки поставки** — окно [выбора поставщика](../vh-dlg/srok.md) и загрузка его файла Excel.
- **Сроки КОМПЭЛ** — файл загружается сразу, затем для каждой строки файла открывается окно [«Выбор резерва счёта»](../vh-dlg/kompel.md); выбранный резерв сохраняется. Отмена выбора прерывает цикл.
- **Письма** — [письма по счёту](../vh-dlg/docs.md).
