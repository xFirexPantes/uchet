# Оплатить / К оплате

Окно открывается из «Входящих счетов» кнопками «+».

**«+» у «Процентов/сумм оплат»** (маленькое окно «Оплатить:»):
- впишите число (по умолчанию 100);
- **процентов** — оплатить процент счёта (целое число, не больше 100);
- **рублей** (на кнопке валюта счёта) — оплатить сумму; флажок **отключить проверку** разрешает сумму сверх счёта (кнопка «процентов» при этом недоступна);
- **отменить** — ничего не делать.

**«+» у «К оплате»** (большое окно): строка заводится сразу при открытии.
- **Дата оплаты** и **Не позднее** — двойной щелчок открывает календарь. Прошедшую дату выбрать нельзя; «не позднее» не может быть раньше даты оплаты. Дату оплаты проверяет база (может ответить своим сообщением).
- **Комментарий для этапа** — текст.
- **К оплате** — число, затем **процентов** или **рублей**. Обе даты обязательны.
- **отменить** (или ✕, Esc) — строка удаляется.
