# Примечание и комментарий счёта

Окно «ввод текста» открывается из «Входящих счетов»:
- кнопкой ✎ рядом с «Примечанием» — правка примечания счёта (до 500 символов);
- двойным щелчком по «Комментарию» — правка комментария (до 1024 символов; длиннее — окно предупредит и сократит).

**✓** сохраняет текст и закрывает окно, текст сразу меняется в списке и на панели. **✕** или Esc закрывает без сохранения.
Если на изменение комментария нет прав, окно скажет «У Вас нет прав на данное действие».
