# Позиция счёта на детали

Окно открывается из карточки счёта на детали: ✎ (правка выбранной позиции) или ＋ (новая позиция).

## Поля
- **Номенклатура**: что заказано. Двойной щелчок по полю открывает окно «Склад»: найдите элемент и нажмите ✓.
  Если элемент уже есть в этом счёте, окно скажет об этом и не закроется.
- **Точное наименование**: наименование, как в счёте поставщика.
- **Количество** и **Цена**: после изменения сумма, НДС и «Всего» пересчитываются сами.
- **Ставка НДС**: ставка для позиции.
- **Сумма / Сумма НДС / Всего**: считаются сами.
- **ScID, ID1C, Who, DT, SkladID**: служебные поля, только просмотр.

## Кнопки
- **✓ Сохранить запись**: записать позицию в счёт и закрыть окно.
- **✕ Выйти без сохранения**: закрыть окно, счёт не меняется.

Пока окно открыто, изменения хранятся во временной записи. В счёт они попадают только по кнопке «Сохранить».
