# Поиск элемента

Открывается кнопкой ＋ в карточке счёта на элементы. Здесь выбирают элемент склада, который нужно добавить в счёт.

## Как искать
- Введите часть названия в поле **Поиск элемента** и нажмите Enter.
- **Принадлежность**: чьи элементы показывать.
- Остальные переключатели (давальческое, только по продукции, аналоги) стоят на своих местах. Часть из них ещё не работает: такие элементы неактивны.

## Как выбрать
- Двойной щелчок по строке или кнопка **✓ Выбрать элемент**. Откроется окно «Позиция счёта» для новой позиции.
- **✕ Закрыть форму**: выйти без выбора.

## Пока не работает
Полный поиск с деревом каталога, карточка элемента по двойному щелчку и загрузка списка из Excel.
