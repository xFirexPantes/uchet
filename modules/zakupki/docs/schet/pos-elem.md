# Позиция счёта на элементы

Окно открывается из карточки счёта:
- кнопкой ✎ (правка выбранной позиции);
- после выбора элемента в поиске (кнопка ＋), чтобы добавить новую позицию.

## Режимы
- **Правка.** Можно менять всё: количество, цену, НДС, даты поставки, информацию.
- **По позиции уже есть накладная.** Сначала будет вопрос. Потом можно менять только цену. Количество, информация, даты и курс заблокированы.
- **Новая позиция.** Окно пустое, элемент уже выбран в поиске.

## Поля слева
- **Кол.поставщика**: количество в единицах поставщика. Если у поставщика другая единица измерения или кратность (упаковка), заполните «Ед. изм. пост.» и «кратность», количество на складе посчитается само.
- **Цена**: цена за единицу в рублях. Если стоит галочка «Включает НДС», цена указана с НДС.
- **НДС,%**: ставка. При смене ставки программа проверяет, подходит ли она этому поставщику.
- **Сумма НДС / Сумма без НДС / Всего**: считаются сами. Галочка «ручной ввод сумм» позволяет ввести суммы вручную.
- **Курс,$** и **Опт,$**: курс и оптовая цена в долларах, считаются сами.
- **Дата поставки** и **1 дата поставки**: ожидаемая и первая обещанная даты. Если дата поставки не указана, при сохранении будет вопрос.
- **Информация**: номер заказа или пометка для позиции.
- **Каталог**: каталог элемента. Двойной щелчок открывает окно выбора.

## Поля справа
Это данные склада по элементу: на складе, резерв, заказано, примечание, минимальное количество, цены, стеллаж и ячейка. Здесь они только для просмотра.

## Кнопки
- **✓ Сохранить**: проверить и сохранить позицию. Программа может предупредить, что цена заметно отличается от прошлых закупок или количество больше нужного. Окно закроется, карточка обновится.
- **✕ Закрыть без сохранения**: закрыть окно, счёт не меняется.

## Пока не работает
Добавление из полного поиска (окно «Поиск элемента» с деревом) и правка количества при накладной по особому праву.
