# Карточка счёта

Открывается двойным щелчком по счёту во «Входящих счетах», в отдельной вкладке.
Счёт на элементы показывается формой «Счёт», счёт на детали формой «Счёт на детали».

## Что видно
- Шапка счёта: продавец, покупатель, ИНН, контрагент, склад, суммы, курс (синий = курс поставщика), путь к оригиналу.
- Позиции счёта. Зелёное наименование: по позиции уже есть накладная.
- Резервы выбранной позиции (щёлкните по позиции).
- Накладные, договоры, список фирм.
- Кнопка «⋯» показывает и прячет дополнительные столбцы позиций (единицы поставщика, цена поставщика и т. д.).
- Зелёный фон формы: счёт по ФЗ-275.

## Правка шапки (счёт на элементы)
Доступна при праве FullSch (у давальческого счёта также EdtDavSch). Поле сохраняется сразу после изменения.
- № счёта, дата счёта: после изменения проверяется, нет ли похожего счёта.
- Сумма счёта: сумма НДС пересчитывается сама по ставке НДС.
- Покупатель: можно выбрать только покупателей с кодом 1 или 8, склад подставляется сам; без права ChgDstSklad склад после этого не меняется.
- «Отдано в оплату»: Delete очищает дату.
- Контрагент: начните набирать название в поле поиска справа вверху, затем дважды щёлкните по фирме в списке.
- Сумма доставки и прочие суммы: спрашивается «Указанная сумма с НДС?». Если «нет», добавляется НДС 22%.
- После смены номера или даты: проверка «Такой счёт уже существует в 1С» и «Уже существует подобный счёт».

## Флажки и кнопки
- ＋ добавляет позицию. Сначала проверяются продавец, покупатель, номер и дата счёта, потом вопрос «Открыть облегченную версию поиска компонента?». Да: окно «Поиск элемента», наберите строку и нажмите Enter (число ищется по коду), при необходимости смените «Принадлежность», выберите строку и нажмите ✓. Если элемент закупается на другую фирму, появится предупреждение. Затем открывается окно позиции: количество, цена, ставка, даты, каталог, ✓ сохраняет. Если не указана дата поставки, спросит «Указать?». Ответ «Нет» открывает полный поиск «Склад» (справка в нём, F1).
- ✎ открывает выбранную позицию в окне правки: количество, цена, НДС, «Включает НДС», единицы поставщика, даты поставки, ручной ввод. Суммы пересчитываются сразу. Если по позиции уже есть накладная, после вопроса можно поменять только цену. ✓ сохраняет, ✕ закрывает без сохранения. Для «10.1 Сырье и материалы» при изменении спрашивается причина и комментарий. Каталог: двойной щелчок по полю открывает окно «Каталог» (поиск по началу), Delete очищает. Если каталога нет в списке, после вопроса можно взять введённый текст.
- «−» удаляет выбранную позицию, если по ней нет накладной. Для не давальческих элементов спрашивается причина (окно «Выбор причины»).
- 💾 у открытого счёта: проверка продавца, покупателя, номера и даты, отметка «изменён сейчас». 🔓 у закрытого счёта открывает его.
- «Оригинал счёта» и «Доп. счёт»: клавиша Delete удаляет путь (после вопроса). «Все накладные» перечитывает список.
- «Не обновлять в 1С», «В 1С» (если счёт ещё не выгружен), «Заберите меня» (спрашивает дату и время), ФЗ-275.
- ФЗ-275: при установке флажка открывается окно «Поиск заказа»: наберите не меньше 3 букв заказа, выберите двойным щелчком или Enter (Esc — отмена). Снять флажок можно сразу.
- «Ставка НДС»: ставка счёта всем строкам.
- ✕: закрытие с проверками, как в Access (похожий счёт, ИНН, склад, позиции, сумма по позициям, обязательные поля). После закрытия список «Входящих счетов» обновляется.

## Счёт на детали
- Пока счёт не закрыт, правятся номер, дата, покупатель, склад, ставка, сумма, сумма НДС, сумма доставки, «Отдано в оплату». Сохраняется сразу после изменения поля.
- Сумма пересчитывает сумму НДС. Для суммы доставки появится вопрос «Указанная сумма с НДС?». Покупатель может быть только 1 или 8, склад после этого подставляется сам.
- Флажки «Счёт не нужен», «В 1С», «Учитывать НДС», «Сумма включает НДС», «Заберите меня» переключаются сразу.
- «Поставка» и «ДП» внизу: выберите дату и нажмите «Установить» рядом, дата встанет всем строкам счёта (после вопроса).
- «Оригинал счёта» и «Доп. счёт»: клавиша Delete удаляет путь (после вопроса).
- ✕ закрывает счёт с проверками, как в Access: даты поставки, похожий счёт (номер очищается), продавец, склад, позиции, сумма, обязательные поля. 🔓 открывает закрытый счёт.
- ＋ добавляет позицию: после проверки номера и даты счёта открывается пустое окно «Позиция счёта для деталей». Номенклатура выбирается двойным щелчком по полю «Номенклатура» (окно «Склад»).
- ✎ открывает выбранную позицию в окне «Позиция счёта для деталей»: точное наименование, количество, цена, ставка, суммы. Количество и цена пересчитывают суммы. ✓ сохраняет позицию, ✕ закрывает без сохранения.
- «Тип счёта» меняется переключателем. 💾 проверяет обязательные поля и похожий счёт. «−» удаляет выбранную позицию (после вопроса). «Все накладные» перечитывает список.
- Пока не работают: выбор файла счёта двойным щелчком по пути, накладные, копирование предыдущего счёта, М15.

## Отличия от Access
- Письма «Неоплаченный счёт» и «Неоплаченный счёт на детали» уходят с сервера, а не из Outlook. С тестовой базы — только на тестовый адрес.
- Проверка лимита договора при закрытии (GetAdr(70)) пока не сделана.
- При добавлении позиции без даты поставки ответ «Да» на «Указать?» возвращает в поле даты, а не сохраняет позицию без даты, как в Access.
- Если не заполнены продавец, покупатель, номер или дата, при закрытии спрашивается «Сохранить изменения?». Ответ «Отмена» удаляет счёт, как «Нет» в Access.
- Столбцы во всех таблицах раздвигаются мышью, ширины запоминаются. Двойной щелчок по краю заголовка возвращает исходные.
- ✕ закрывает вкладку.
